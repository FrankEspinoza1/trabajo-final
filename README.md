K POP Librería 📚

Proyecto web responsive desarrollado para la gestión y visualización de productos de librería y papelería profesional.

Características

- Diseño responsive adaptable a móviles y escritorio
- Catálogo de productos
- Carrito de compras dinámico
- Filtros por categoría y precio
- Animaciones y efectos visuales
- Persistencia de carrito con LocalStorage
- Integración con Firebase Firestore
- Productos cargados dinámicamente desde Firebase
- Hosting online con Firebase

Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Firebase Hosting
- Firebase Firestore
- Git & GitHub
